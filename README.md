# Olá, me chamo Vitor Oliveira 👋

**Desenvolvedor Full Stack** · Estagiário na ControlXRM - Software · Ciência da Computação na UNIP · São Paulo, SP

Desenvolvedor Full Stack atuando em aplicações **SaaS B2B** para grandes operadores de aeroportos e shoppings. Trabalho no desenvolvimento e evolução de sistemas críticos utilizando **C# / .NET / Razor**, **React**, **Microsoft SQL Server** e **APIs REST**, em ambiente ágil **Scrum**.
